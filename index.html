• Git(vcs)version control system - Loyihadagi o‘zgarishlarni saqlab boradigan tizim.
  • Gitbash - Git buyruqlarini yozish uchun terminal.
  • Github - Loyihani internetda saqlaydigan sayt.

Git sozlamalari (bir marta):

  • git config --global user.name "YourName"
  • git config --global user.email "youremail@gmail.com"

Loyihani GitHub'ga joylash (birinchi marta):

  • git init — loyihaga Git o‘rnatish
  • git add . — barcha fayllarni Git’ga qo‘shish
  • git commit -m "First commit" — birinchi saqlash
  • git branch -M main — asosiy branch nomini main qilish
  • git remote add origin LINK — GitHub repository bilan bog‘lash
  • git push -u origin main — loyihani GitHub’ga yuklash

Keyingi o‘zgarishlarni GitHub’ga yuborish:

  • git add . — yangi o‘zgarishlarni qo‘shish
  • git commit -m "Update project" — o‘zgarishni saqlash
  • git push — GitHub’ga yuborish
